## 1. Executive Summary

`trg v0.14.1` is an audited maintenance release focusing on scanner memory optimization, regression test gate hardening, and contract baseline compliance:

1. **Scanner Streaming Memory Reduction**:
   - Short-circuits intermediate `LogicalLine` construction in `src/scanner.tk:851` during non-context line processing.
   - Tested empirically across 2 / 6 / 18 MiB test files: RSS remains flat at ~2.7–3.0 MiB (~1.12x scaling ratio), compared to `v0.14.0` scaling up to 22.48 MiB (~4.48x).
2. **Universal Regression Gate (38 / 38 Assertions)**:
   - Covers diverse data shapes (LF, CRLF, trailing newlines, zero bytes, multi-pattern, UTF-8, case folding) and protocol formats (CLI, JSON, MCP 2024/2025).
   - Independent canonical UTF-8 byte accounting prevents serialization discrepancies for non-ASCII contents.
3. **Byte-for-Byte Differential Parity (16 / 16 Vectors)**:
   - Raw binary diffing confirms zero regression or drift compared to public `v0.14.0`, isolating diffs strictly to the declared MCP version metadata.
4. **Standalone Binary Deliverable Verification**:
   - Release binaries are independently audited via `tests/verify_standalone_binary.py` to ensure runtime behavior, license presence, and performance match source claims.

## 4. Contract Disclosures & Known Gaps

Reference: [`docs/contracts/search_and_perception_contract.md`](file:///Users/zhyi/GitDP/tokalang/trg/docs/contracts/search_and_perception_contract.md)

- **GAP-001**: Unregistered extensions default to `BraceScopeParser`.
- **GAP-002**: Indentation-delimited languages with unregistered extensions cannot deduce scopes.
- **Scope Model**: Purely lexical and symbol-based parsing; no full AST/CST semantic engine is claimed.
- **Windows / WSL**: Native Windows binary support is pending dedicated porting; WSL2 is the verified Windows runtime path.
