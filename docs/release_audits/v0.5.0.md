## 4. Technical Notes & Calibration (v0.5.1 Roadmap)

1. **Chunked File I/O with Full Logical-Line Buffering**:
   - The scanner performs streaming 64KB block reads with full in-memory logical line accumulation.
   - For ultra-large continuous lines (>16MiB), cumulative string copying during chunk carry accumulation exhibits quadratic re-allocation overhead (e.g. 4MiB ~0.14s, 16MiB ~1.16s, 32MiB ~4.80s).
   - In v0.5.1, the scanner will be optimized with persistent chunk-slice buffers and linear in-place carry stitching.
2. **`-m` Context Draining Compatibility Note**:
   - Under strict match capping (`-m`), any pattern match encountered within a trailing context draining window (`-A` / `-C`) is formatted as a context line (`-`) rather than a match line (`:`).
   - Ripgrep treats such occurrences as match lines (`:`) while respecting the count cap; this known formatting difference is documented for downstream consumers.
