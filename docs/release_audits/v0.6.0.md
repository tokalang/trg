## 1. Executive Summary

`trg v0.6.0` delivers the full ripgrep CLI compatibility core (`-q`, `-o`, `-c` zero omission & `--include-zero`, multi `-e`, `-f`, `--sort path`, `--sortr path`, `-N`), closing friction points for AI Coding Agents and developer scripts while preserving trg's deterministic performance and strict error-precedence contracts.

### Key Capabilities & Architectural Enhancements:
1. **Zero Omission by Default in `-c` & `--include-zero` Support**:
   - Matches `rg` contract: `-c` omits files with zero matches by default (`matches_count > 0 || opts.include_zero`).
   - `--include-zero` flag explicitly includes zero-match files (`file:0`) in `-c` output.
   - Preserves exit code semantics: exit code `0` on at least one match, exit code `1` when total matches are `0` (regardless of `--include-zero`).
2. **Quiet Existence Probe (`-q / --quiet`)**:
   - Immediate short-circuit on the first match with zero terminal match output.
   - Enforces the ripgrep **match-beats-error** precedence exception: returns exit code `0` upon match even if invalid or unreadable file paths produced I/O errors during traversal.
   - In `--json` mode, suppresses per-file events and cleanly emits a single global `summary` event (`trg-json-v2`) before exiting.
   - In `--files` mode, suppresses output and exits `0` if target files exist (even if accompanied by non-existent paths).
3. **Only-Matching Extraction (`-o / --only-matching`)**:
   - Line-by-line extraction of isolated matching substrings with accurate 1-based line number (`-n`) and file path prefixes.
   - Context zeroing: automatically sets `before_context = 0` and `after_context = 0` to bypass `BeforeRing` memory limits.
4. **Multi-Pattern Engine (`-e / --regexp`, `-f / --file`)**:
   - Supports multiple pattern flags (`-e <PAT>`, `--regexp <PAT>`) and file loading (`-f <FILE>`, `--file <FILE>`).
   - Strict **leftmost-first evaluation priority** across multi-pattern literal scans and Thompson NFA alternation `(pat1)|(pat2)`.
   - Multi-pattern Smart Case (`-S`): case-sensitive if any pattern contains ASCII uppercase characters, else case-insensitive.
   - Empty pattern file (`-f /dev/null`) support: exits code 1 with 0 matches across both literal and regex modes.
   - Blank line pattern (`""`) support: matches every line.
5. **Deterministic Lexicographical Traversal (`--sort path`, `--sortr path`)**:
   - Replaced $O(N^2)$ insertion sort with $O(N \log N)$ auxiliary buffer Merge Sort.
   - Benchmarked 10,000 files in **0.1949s** with strict lexicographical ordering.
6. **CLI Order-Independence & `--` Delimiter**:
   - Two-phase positional argument resolution: non-flag arguments are gathered into `raw_positionals` before partitioning patterns and paths, ensuring positional arguments can appear anywhere before or after `-e/-f`.
   - Standard `--` delimiter treats all trailing tokens as raw paths/positionals.
7. **Disambiguated Regex Mode (`-E`, `--extended-regexp`, `--regex-mode`)**:
   - Dedicated `--regexp <PATTERN>` exclusively to pattern arguments.
   - Renamed `-E` regex mode switches to `--extended-regexp` and `--regex-mode`.
