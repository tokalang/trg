## 1. Executive Summary

`trg v0.14.0` delivers Batch 1 feature enhancements and robust architectural hardening:

1. **Syntactic Code-Only Lexical Filtering (`--code-only` / `--no-code-only`)**:
   - Matches only in executable source code, skipping string literals, character literals, single-line comments, and block comments.
   - Language-dialect aware: respects `#` comments (Python, YAML, Shell, Ruby) vs code mutability/attributes (Toka `#`, Rust `#[...]`, JS `#private`), `//` and `/* ... */` (C-like, Toka, JS/TS, Rust, Go, Java), and multiline template/string boundaries.
   - Integrated into CLI search options with symmetric negation (`--no-code-only`, last-wins semantics) and typed MCP parameter (`code_only: bool`, default `false`).

2. **MCP Structured View Visibility (`format: "json"`)**:
   - `trg_view` supports `format: "json"` in addition to default `format: "text"`.
   - Emits canonical `trg-mcp-view-result-v1` serialized as JSON into `content[0].text`.
   - Protocol negotiation: under MCP `2025-11-25`, emits both `content[0].text` and matching typed `structuredContent`. Under `2024-11-05`, emits `content[0].text` while preserving legacy compatibility.

3. **Strict MCP Tool Error Schema Compliance**:
   - When a tool call errors (`isError: true`), `structuredContent` is omitted entirely rather than returning a mismatched error shape.
   - Machine-readable JSON error payload is retained in `content[0].text` for parsing, avoiding client schema validation failures against declared `outputSchema`.

4. **Hard Byte Budget Convergence (`converge_structured`)**:
   - Dynamically tracks UTF-8 serialization lengths until `content_bytes_emitted` converges with actual string length.
   - Eliminates digit-transition overflow (e.g. 998 $\to$ 1001 bytes) at decade boundaries (999/1000, 9999/10000).
   - Bounds convergence to a maximum of 10 iterations; returns a controlled error if convergence fails.

5. **$O(B + N)$ Linear Record Pruning & Upstream Bounded Reader**:
   - Precomputes individual record JSON lengths once ($O(B)$), avoiding quadratic whole-buffer re-encoding.
   - Employs binary search and integer boundary calculations ($O(N)$) to select the candidate record window.
   - Restores upstream byte limiter (`exec_max_bytes = max_bytes_opt`), terminating file scans early when budget is reached while preserving target records in point/block modes and supporting empty emitted ranges in range mode.
