## 1. Executive Summary

`trg v0.13.1-rc1` resolves all architectural contradictions, protocol edge cases, and dogfooding audit findings identified during comprehensive AI agent usage:

1. **Target Preservation Invariant & Fail-Closed Target Budget Contract**:
   - Point and block hydration are mathematically guaranteed to include the target line if successful.
   - Streaming engine allocates budget with target reservation: the target line is buffered and budgeted first before allocating surrounding context via an $O(\text{max\_block\_lines})$ `BeforeRing`.
   - If the canonical atomic target record itself exceeds `max_result_bytes`, the operation fails closed immediately:
     - **MCP Server**: Emits `result.isError: true` with error identifier `target_exceeds_max_result_bytes`.
     - **CLI**: Writes diagnostic to `stderr` and terminates with exit code `2`.
     - Zero irrelevant context is emitted; byte limit is strictly preserved.
2. **Dual Coordinate Space for Snippets (Canonical Source vs KWIC Projection)**:
   - Resolves the dilemma between source coordinate accuracy and KWIC snippet delivery.
   - `record.text` always contains the full canonical source line; `submatches` always specifies byte slices within `record.text`.
   - Dedicated `snippet` field (`{ text: string, submatches: Vec<SubMatch> }`) provides optional compact KWIC projections without distorting source line coordinates.
3. **Formal MCP `trg-mcp-view-result-v1` Schema & Protocol Parity**:
   - `trg_view` advertises `outputSchema` with `$id: "trg-mcp-view-result-v1"` under MCP protocol version `2025-11-25`.
   - Structured content strictly validates against schema invariants: mode-aware field purity (`requested_line: null` and `target_included: null` in range mode).
   - Flexible `lines` parameter supports both `[start, end]` integer arrays and `"start-end"` strings.
   - View truncation notice is cleanly separated from code text (directed to `stderr` in CLI, reported via metadata in MCP).
4. **Delimiter-Aware Tokenizer & Scope Delimiter Pairing**:
   - Tokenizer isolates Toka lifetime identifiers (`'rem`, `'c`, `'val`) without entering character or string literal modes.
   - `ScopeFrame` tracks `(name, delimiter, baseline_depth)`: Shape scopes close precisely on matching `)` (`Paren`), and functions/classes close on `}` (`Brace`).
   - Rejects local variable assignments (`auto x = (`, `let y = (`) from polluting `ScopeTracker`.
   - Single-line blocks (`fn foo() { return 1; }`) self-close immediately.
   - Graceful EOF closure without trailing newlines for brace, paren, and indentation blocks.
5. **Single-Pass Structural Lexical Masking & Dialect-Specific Comment Rules**:
   - `scan_line_lexical` masks comments and string contents to whitespace in a single pass while preserving code tokens and delimiters.
   - Comment isolation: `#` is treated as a line comment strictly for `LexicalDialect::HashComment` (`py`, `pyi`, `yaml`, `yml`, `nim`, `sh`, `bash`, `zsh`, `rb`, `pl`, `r`); in Toka (mutability `#`), Rust (`#[]`), and JS (`#private_field`), `#` is treated as code.
   - Structural facts separation: `LogicalLine` stores scalar flags (`depth_before_brace`, `depth_before_paren`, `participates_in_indent`, `statement_indent`, `is_scope_decl`, `starts_block`, `has_code_brace_closer`, `has_code_paren_closer`) without duplicating masked string buffers across the 1000-line ring.
   - `ScopeTracker` consumes structural facts directly, popping on dedented module-level expressions even when string-masked, and ignoring multiline string interior lines.
   - Commented-out definitions in `/* ... */` or docstrings `"""` never trigger the runaway definition guard and are ignored by `--def-first`.
6. **Extended Glob Profile v2**:
   - Full support for `?` (single char), `[...]` (character classes, ranges, and negation `[!...]`), and `\` (escape literals).
   - Upfront syntactic validation: unclosed brackets `[...]` fail fast with exit code `2` before directory traversal.
7. **Strict JSON Pre-Validation**:
   - Pre-validates incoming JSON-RPC payloads before invoking the parser to enforce RFC 8259 compliance.
   - Rejects numbers with leading `+`, leading zeros (`01`), unclosed decimals (`2.`), malformed exponents (`1e`), and unescaped control characters with JSON-RPC error code `-32700`.
8. **Flag Symmetry & CLI Polishing**:
   - Last-wins precedence for `-s` / `--case-sensitive` vs `-i` / `--ignore-case`.
   - 64-bit integer overflow protection across all numeric CLI arguments.
   - Synchronized `--help` documentation for `--sort <TYPE> (default: none)`.

## 2. Key Architectural Components

### 2.1 Single-Pass Streaming View Engine (`src/view.tk`)
- **Target Line Reservation**:
  - Point and block hydration pre-calculate budget requirements for the target line.
  - Context lines are accumulated in an $O(\text{max\_block\_lines})$ circular buffer (`BeforeRing`).
  - When the target line is reached, it is immediately committed; preceding lines are flushed from the ring buffer up to the available context budget; succeeding lines are streamed until `cur_line >= end_line` or budget exhaustion.
- **Fail-Closed Target Budget Check**:
  - If `target_bytes > max_result_bytes`, processing halts immediately with `TargetExceedsMaxResultBytes`.
- **EOF & Trailing Newline Robustness**:
  - The final chunk line buffer is evaluated for delimiter balance, block boundaries, and runaway definition guards even when missing a trailing newline (`\n`).

### 2.2 Dual Coordinate Space (`src/types.tk`, `src/scanner.tk`, `src/printer.tk`, `src/mcp_result.tk`)
- **`SnippetProjection` Shape**:
  ```toka
  pub shape SnippetProjection (
      text: string,
      submatches: Vec<SubMatch>
  )
  ```
- **`InternedRecord` Integration**:
  - `record.text`: Preserves full original source line text.
  - `record.submatches`: Exact UTF-8 byte offsets into `record.text`.
  - `record.snippet: Option<SnippetProjection>`: Compact KWIC window with remapped offsets.
- **Serialization Parity**:
  - Human terminal output formats `snippet.text` when `--snippet` is enabled.
  - JSONL (`trg-json-v2`) and MCP (`trg-mcp-result-v2`) serialize both full source text/submatches and the dedicated `snippet` object.

### 2.3 Delimiter-Aware Tokenizer & Scope Tracking (`src/syntax.tk`)
- **Lifetime vs Character / String Disambiguation**:
  - A single quote `'` followed by an identifier character is classified as a Toka lifetime (or character literal) and does not put the tokenizer into a runaway string state.
- **Delimiter-Typed Scope Frames**:
  - `ScopeFrame` binds delimiter types (`BlockDelimiter::Brace`, `BlockDelimiter::Paren`, `BlockDelimiter::Indent`).
  - When closing delimiters `)` or `}` are encountered, the tracker matches delimiter type and baseline depth, preventing paren expressions from prematurely popping brace-delimited scopes.

### 2.4 Extended Glob Profile v2 (`src/glob.tk`)
- Extended pattern compilation parses `[...]`, `?`, `*`, `**`, and escaped characters.
- Upfront dialect check verifies bracket closure; returns `Result::Err` immediately if syntax is invalid, triggering exit code `2` before any file I/O or directory traversal occurs.
