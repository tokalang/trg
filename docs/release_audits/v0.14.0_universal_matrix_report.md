## 3. Isolated Peak RSS & Scaling Benchmarks

Measurements performed using isolated child processes via `os.fork` and `os.wait4` (standardized to MiB):

### 3.1 Streaming File Size Scaling (Fixed Line Length 100 chars, Density 1/1000)
- **2 MiB Scale**: 3.17 MiB RSS (runs: `[3.09, 3.22, 3.88]`)
- **6 MiB Scale**: 3.47 MiB RSS (runs: `[3.42, 3.47, 3.61]`)
- **18 MiB Scale**: 3.67 MiB RSS (runs: `[3.50, 3.67, 3.88]`)
- **Growth Ratio Across 9x File Expansion**: **1.14x** (Slope $\approx 0.03 \ll 1.0$)
- **Verdict**: **PASS**. Peak RSS remains constant-bounded under 4 MiB, confirming true $O(1)$ chunk-buffered streaming scan.

### 3.2 Long-Line Scaling (Single Line Expansion)
- **4 MiB Line**: Median scan time **0.0196s** (runs: `[0.0195s, 0.0196s, 0.0201s]`)
- **16 MiB Line**: Median scan time **0.0644s** (runs: `[0.0618s, 0.0644s, 0.0649s]`)
- **Scaling Ratio ($T_{16} / T_4$)**: **3.28x** (Linear theoretical limit $\approx 4.0\text{x}$, quadratic threshold $\ge 16.0\text{x}$)
- **Verdict**: **PASS**. Strict linear time scaling verified with zero quadratic degradation.
