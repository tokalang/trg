## 5. Memory Scaling & Isolated RSS Measurement

Isolated peak RSS measured per-process using `os.fork` and `os.wait4` with non-blocking poll, 15s timeout, and SIGKILL-backed zombie process cleanup.

### 5.1 File Size Scaling (Fixed Line Length 100 chars, Match Density 1/1000)
- **Benchmark Configuration**:
  - Scales: 2 MiB, 6 MiB, 18 MiB (9x file size expansion, 16 MiB delta)
  - Repetitions: 3 runs per scale after initial warmup, median recorded
  - Gate Criterion: Memory growth ratio across 9x expansion $< 3.0\text{x}$
- **Empirical Measurements**:
  - **Public Baseline Release `v0.14.0`**:
    - 2 MiB: 5.09 MiB
    - 6 MiB: 9.86 MiB
    - 18 MiB: 22.86 MiB
    - Delta: +17.77 MiB RSS across +16.0 MiB input ($\Delta\text{RSS}/\Delta\text{Size} \approx 1.11 \text{ MiB/MiB}$)
    - Ratio: **4.49x** (Gate: **FAIL**)
  - **Patch Candidate (Proposed `v0.14.1`)**:
    - 2 MiB: 3.53 MiB
    - 6 MiB: 3.48 MiB
    - 18 MiB: 3.45 MiB
    - Delta: -0.08 MiB RSS across +16.0 MiB input ($\Delta\text{RSS}/\Delta\text{Size} \approx 0.00 \text{ MiB/MiB}$)
    - Ratio: **0.98x** (Gate: **PASS**)

### 5.2 Long-Line Scaling ($T_{16}/T_4$ Time Ratio)
- **4 MiB Line**: Median scan time **0.0192s**
- **16 MiB Line**: Median scan time **0.0617s**
- **Scaling Ratio**: **3.21x** (Linear theoretical limit $\approx 4.0\text{x}$, quadratic threshold $\ge 16.0\text{x}$)
- **Verdict**: **PASS**. Confirms $O(L)$ linear performance with zero quadratic degradation.

## 7. Audit Conclusions & Recommendations

1. **v0.14.0 Baseline Release Integrity**:
   - The public `v0.14.0` binary is fully qualified across general search, boundary control, case modes, multi-pattern, UTF-8 offsets, MCP search/view budgets, and long-line scaling.
   - The public release does not meet the strict streaming constant-bound memory gate ($< 3.0\text{x}$ over 9x file size expansion) due to unoptimized logical line buffering.
2. **Proposed v0.14.1 Patch Readiness**:
   - The scanner optimization (`src/scanner.tk:851`) solves the memory scaling issue, eliminating linear RSS growth during non-context scanning.
   - The patch preserves 100% byte-for-byte output parity across all 16 test vectors in `tests/verify_differential_parity.py`.
   - Ready to enter formal v0.14.1 patch acceptance and tagging workflow.
