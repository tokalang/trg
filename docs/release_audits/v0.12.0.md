## 1. Executive Summary

`trg v0.12.0 (AI-Native Evolution)` delivers three major agent-centric advancements designed to minimize roundtrips and token consumption for AI coding workflows:
1. **Physical Edit-Ready Block Boundaries (`block_range: [start, end]`)**: Delivers accurate, closed physical line ranges on match records across Text (`[block: L{start}-L{end}]`), JSONL (`trg-json-v2`), and MCP (`trg-mcp-result-v2`).
2. **Zero-AST Caller Scope Grouping (`--group-by-scope` / `group_by_scope: bool`)**: Clusters matching lines under enclosing function/class/struct headers in grouped mode, with inline `[<scope>]` prefix degradation in flat layout.
3. **Case-Convention Invariance (`--symbol-variants` / `symbol_variants: bool`)**: Expands a single identifier across 5 casing conventions (`snake_case`, `camelCase`, `PascalCase`, `SCREAMING_SNAKE_CASE`, and `kebab-case`) with 2-phase acronym lookahead and case-insensitive deduplication under `-i`.

## 2. Key Architecture & Protocol Specifications

### 2.1 Atomic Block Windowing & Multi-Match Collapse
- **$O(1)$ Auxiliary Space Invariant**: Preserves streaming throughput with bounded buffer memory proportional only to `--max-block-lines` (default 80, max 1000).
- **Temporal Closure Resolution**: Buffers matches and surrounding context in `block_window` until block closure (brace `}` or indent un-nesting), truncation, or EOF is encountered, retroactively stamping exact physical boundaries `[start, actual_end]`.
- **Multi-Match Collapse**: Multiple matches within the same function share the single window and identical `block_range`, preventing fragment blowout.

### 2.2 Caller Scope Grouping
- **State Isolation**: Resets `last_scope` state on file traversal boundaries and across Pass 1 (Definitions) $\to$ Pass 2 (Usages) transitions in `--def-first`.
- **Format Graceful Degradation**: Grouped layout (`--heading`) renders distinct `scope: <caller>` headers; flat layout (`--no-heading`) prepends `[<scope>]` directly to the line prefix without disrupting Unix grep linewise tools.

### 2.3 Identifier Variants & Acronym Handling
- **Defense in Depth**: Strict front-end lexical validation (`^[a-zA-Z_][a-zA-Z0-9_-]*$`); rejects spaces, operators, and digits at index 0 with exit code 2 / MCP `-32602`.
- **Acronym Lookahead**: Lookahead state machine splits `HTTPServer` into `HTTP` + `Server` rather than single-letter tokens `h_t_t_p`.
- **Case-Insensitive Deduplication**: In `-i` / `case_mode: "ignore"`, deduplicates casing variants that fold to identical lowercase representations.
