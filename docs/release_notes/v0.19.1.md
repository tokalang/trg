# trg v0.19.1 Release Notes

**Release**: `v0.19.1`<br>
**Release Date**: 2026-09-10<br>
**Target Platforms**: `linux-x64`, `macos-arm64`, `windows-x64`, `windows-arm64`<br>
**Toolchain**: Toka SDK 1.0.0-rc.11, Clang/LLVM, MSYS2 MinGW-w64 / CLANGARM64

---

## 1. Overview

`trg v0.19.1` 是一个聚焦于**续读体验优化**与**搜索作用域边界增强**的补丁小更新：

1. **续读提示保留预算与 Token 去重 (View Continuation Hint Budget Preservation & Stderr Dedup)**:
   - CLI 续读提示命令自动保留用户传入的预算参数（`--max-lines` / `--max-result-bytes`），避免续读时预算遗失导致一次性倾泻长内容；
   - 移除 CLI stderr 中多余的重复 Token 输出，确保凭据仅在终端提示行中展示一次，显著降低模型终端感知噪声。
2. **搜索作用域边界与可靠性呈现 (`--scope` Syntactic Boundary Projection)**:
   - 在搜索模式下开启 `--scope` 时，若命中位于已确认的作用域中，首次实际输出的命中展示完整的符号范围与解析可靠性：`[<name> <start>-<end>; <reliability>]`（如 `[compute 2-5; confirmed]`）；
   - 同一作用域内的后续命中自动紧凑去重为 `[<name>]`，兼顾首次上下文感知与高频命中的 Token 效率；
   - 去重状态在输出层成功发送后更新，若前置词法命中被筛选过滤（如 `--code-only` 过滤注释），下一个实际输出的代码命中正确呈现完整边界。
3. **资源保护硬上限与符号表估算预算 (Resource Caps & Safety)**:
   - **单文件输入读取硬上限（4 MiB）**：`outline_symbols_file` 在底层 `libc_fread` 循环前严格按上限截断单次与累计物理读取量，超限立即中止解析并优雅降级；
   - **符号数量硬上限（2,048 个）**：单个文件解析符号数达到 2,048 时立即截断 outline 收集，杜绝超大定义文件开销；
   - **符号表估算预算（2 MiB）**：严格以 `120 + name.len + scope.len` 估算累计控制 outline 输出规模。
4. **接口投影与向后兼容保障 (Interface Projections & Schema Purity)**:
   - **CLI JSON**：`scope` 包含自包含元数据 `{ text, name, kind, range_start, range_end, reliability }`，其中 `scope.text` 保留完整函数声明签名（长签名不被截断），`scope.name` 提供简短标识符；
   - **MCP Text**：`content[0].text` 与终端保持一致，包含 `[name start-end; reliability]` 面包屑；
   - **MCP Structured**：`records[].scope` 严格保持 `string | null` 签名类型，完全遵守 `trg-mcp-result-v2` 的 `additionalProperties: false` 强类型约束（通过 Test 112 实时校验）。

---

## 2. 技术边界与保留说明 (Technical Boundaries & Clarifications)

1. **作用域可靠性定义 (Semantic Scope Contract)**:
   - `reliability = "confirmed"` 仅代表基于 outline 解析时刻代码词法/AST 规则确认的语法闭合依据，不宣称与流式行搜索具有物理上的原子快照一致性。
   - 文件若在搜索与 outline 期间发生外部改动，或 outline 解析触发资源上限截断，系统优雅降级为未确认/无 scope 状态，绝不伪造虚假范围。
2. **MCP 结构化字段约束 (MCP Schema Compatibility)**:
   - 新增的数值范围（`range_start`/`range_end`）与可靠性（`reliability`）仅存在于 CLI JSON 与各接口的文本投影中，MCP `structuredContent` 中 `records[].scope` 保持字符串类型，确保现有所有 MCP 客户端零适配成本。
