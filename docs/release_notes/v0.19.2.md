## 1. Overview

`trg v0.19.2` 是一个聚焦于**命令行参数诊断**与**检索调用规范明确化**的维护补丁版本：

1. **`view --scope` 参数校验与诊断改善 (View Scope Validation & Actionable Diagnostics)**:
   - 增强 `trg view --scope` 的参数解析校验：当 `--scope` 缺失取值或直接紧跟其他选项标志（如 `-n`, `-C`, `--max-lines`）时，输出明确、可操作的错误诊断；
   - 校验 `--scope=` 赋值语法，杜绝空值传递；
   - 同步收紧并对齐 MCP 协议层工具声明（`trg_view` 与 `trg_search`）中的参数描述与校验语义，引导客户端传递合法的限定参数。

2. **文件与管道输入的明确用法 (Explicit Path Requirement & Piped Input Contract)**:
   - 明确文件检索的路径规范：在 CLI 检索文件时显式提供目标路径（例如 `trg -F "pattern" .` 或 `trg "pattern" src/`），避免缺省目标时在开放管道环境下等待输入；
   - 规范管道流检索语法：在需要从标准输入读取流数据时，显式指定 `-`（例如 `cat file | trg "pattern" -`）。

3. **按需使用作用域与局部阅读指导 (Targeted Scope Usage & Bounded Reading Guidance)**:
   - 更新 CLI 帮助信息与工作流示例：普通文本检索推荐直接配合行号与局部上下文（如 `trg -F "pattern" src/ -n -C 5`）；
   - 明确 `--scope` 定位：仅在关心匹配行所属函数、类或类型外层归属时按需启用 `--scope`；
   - 强调局部阅读与安全预算：已知符号时使用 `trg view <path> --symbol <name>` 并配合安全预算（如 `--max-lines 120` 或 `--max-bytes 8K`），已知行号所在代码块时使用 `trg view <path>:<line> --block`，减少大函数无差别展开。
