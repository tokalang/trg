## 1. Overview

`trg v0.19.6` delivers critical accuracy and scope resolution enhancements for **TypeScript**, **JavaScript**, and **Single-File Components (Vue, Svelte, Astro)**, resolving scope leakage, false hierarchy nesting, and enabling full symbol block hydration:

1. **Inline Type Import & Export Defense (TRG-001 Directive A)**:
   - **Elimination of False Hierarchy Nesting**: In TypeScript/JavaScript files with inline type specifiers (e.g., `import { type PreviewMatch, type PreviewSearchState } from "./types"`), previous versions mistakenly extracted `PreviewMatch` as a top-level block scope declaration. Because the line lacked a closing brace, subsequent definitions (such as `PreviewSearchState`) were falsely nested as children (e.g. `PreviewMatch::PreviewSearchState`).
   - **Specifier Classification Guard**: `extract_declared_identifier_with_dialect` and `is_scope_declaration_with_dialect` now inspect identifier boundaries. Tokens followed by `,`, `as `, `}`, or `from ` within import/export contexts are excluded from symbol extraction and scope tracking.

2. **ASI Single-Line Type Alias Defense (TRG-001 Directive B)**:
   - **Automatic Semicolon Insertion (ASI) Protection**: TypeScript frequently omits terminating semicolons on single-line type aliases (e.g. `type PreviewPdfPage = PDFPageProxy`). Previously, without a trailing `;` or braces, the scanner treated the statement as an open multiline block, swallowing subsequent interfaces, classes, or functions into its scope.
   - **Heuristic ASI Boundary Resolution**: Introduced `is_single_line_type_alias` in `src/syntax.tk`. Statements matching `type <Name> = <Type>` that contain `=` without `{`, and do not terminate with multiline continuation operators (`=`, `|`, `&`, `,`, `(`, `[`, `?`, `:`), are classified as self-closing (`is_self_closed = true`, `range_reliability = "single_line"`). They are recorded with accurate 1-line spans and never pushed to `open_stack`.

3. **Vue, Svelte, and Astro SFC Symbol View Support (TRG-002)**:
   - **Hydration Parity**: `.vue`, `.svelte`, and `.astro` Single-File Components were previously supported in `trg symbols` outline extraction, but rejected by `trg view <file> --symbol <name>` with `unsupported syntax for symbol view`.
   - **Whitelist Inclusion**: Added `.vue`, `.svelte`, and `.astro` to `is_symbol_view_supported` in `src/syntax.tk`, providing seamless point hydration and full implementation retrieval for AI agents and developers working on modern web frontend codebases.

4. **Qualification & Verification**:
   - Expanded the rigorous qualification suite to **182 tests**, introducing Test 182 (`tests/test_ts_vue_symbols.py`) to systematically verify inline type imports, ASI type aliases, multiline object type aliases, and Vue SFC symbol extraction and hydration.
   - All 182 qualification tests pass with 100% green status.

## 3. Quick Installation

### macOS & Linux
```bash
curl -fsSL https://raw.githubusercontent.com/tokalang/trg/main/install.sh | sh
```

### Windows (PowerShell)
```powershell
irm https://raw.githubusercontent.com/tokalang/trg/main/install.ps1 | iex
```

### Windows (WinGet)
```cmd
winget install --id Tokalang.trg -e
```
