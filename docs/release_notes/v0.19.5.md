## 1. Overview

`trg v0.19.5` is a critical reliability and ignore-hierarchy correctness release addressing **Git root `.gitignore` inheritance in subdirectory searches**, **`.git/info/exclude` discovery**, and **memory safety under Toka 1.0.0-rc.13**:

1. **Hierarchical Git Root & Parent Directory Ignore Inheritance**:
   - **Subdirectory Target & CWD Inheritance**: In previous versions, targeting a subdirectory (e.g. `trg --files src/` or running `trg` from within a nested directory) evaluated ignore rules solely from the local target directory downwards, failing to inherit the Git root `.gitignore`. In monorepos and standard projects, this caused build artifacts and cache folders (such as `target/`, `node_modules/`, `dist/`, `build/`) defined at the repository root to be traversed, resulting in excessive I/O, search noise, and token bloat in AI Agent workflows.
   - **Upward Git Root Walk**: `trg` now walks upward from the search target to identify the enclosing Git root directory (checking for `.git`), anchoring rule layers hierarchically from repository root down to the target path.
   - **Repository-Local Excludes (`.git/info/exclude`)**: Full upward discovery of `.git/info/exclude` rules, ensuring personal/local ignore patterns are consistently applied across both root and subdirectory queries.
   - **Scoped Rule Anchoring**: Root-anchored rules (e.g., `/build` or `/target/`) are strictly confined to their declaring directory boundary, while unanchored patterns (e.g., `target/` or `*.log`) match recursively across subtrees.
   - **Non-Git Graceful Degradation**: Traversals outside Git repositories continue to honor directory-local `.gitignore` files with zero overhead and no fallback failures.

2. **Ownership Safety & Destructor Lifecycle**:
   - Refactored `populate_initial_ignore_stack` to mutate the owned `IgnoreStack` directly in-place across directory boundaries, eliminating field deconstruction from intermediate shapes and ensuring robust single-ownership destructor semantics under Toka 1.0.0-rc.13.

3. **Qualification & Verification**:
   - Expanded the rigorous qualification test suite to **181 tests**, introducing Test 181 (`tests/test_parent_ignore_inheritance.py`) to systematically verify multi-tier ignore inheritance, `.git/info/exclude`, root-anchored rules, `--no-ignore` overrides, and non-Git path queries.
   - All 181 qualification tests pass with 100% green status.

## 3. Quick Installation

### macOS & Linux
```bash
curl -fsSL https://raw.githubusercontent.com/tokalang/trg/main/install.sh | sh
```

### Windows (PowerShell)
```powershell
irm https://raw.githubusercontent.com/tokalang/trg/main/install.ps1 | iex
```

### Windows (WinGet)
```cmd
winget install --id Tokalang.trg -e
```
