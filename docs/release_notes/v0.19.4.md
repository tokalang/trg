## 1. Overview

`trg v0.19.4` is a critical stability and ecosystem release focusing on **official Toka 1.0.0-rc.13 toolchain & dependency adaptation**, **cross-dialect scope isolation**, and **eliminating scope stack deadlocks**:

1. **Official Toka 1.0.0-rc.13 Toolchain & Dependency Ecosystem Adaptation**:
   - Upgraded core dependency to `tokalang/regex:0.3.1`, fully qualified under Toka RC13 explicit call-site `cede` contracts and published to the official package registry (`pkg.tokalang.dev`).
   - Re-architected MCP JSON parsing and serialization to use standard library document models conforming to RC13 value semantics.
   - Locked all four-platform CI/CD qualification and release workflows to the official Toka `1.0.0-rc.13` release artifacts with verified SHA-256 digests.

2. **Cross-Dialect Scope Isolation & Depth-0 Stack Underflow Deadlock Fix**:
   - **Lexical Dialect Isolation**: Isolated Toka's exclusive `shape` keyword declaration semantics strictly to `LexicalDialect::Toka` (`.tk` files). In C/C++, variable names or expressions named `shape` (such as `shape = findVisibleShapeDecl(...)`) are no longer misidentified as type declarations.
   - **Assignment & Punctuation Guard**: Statements immediately followed by assignment operators (`=`) or punctuation (`;`, `,`, `.`, `)`, `}`, `]`) are strictly rejected as declaration scopes.
   - **Depth-0 Stack Deadlock Elimination**: Resolved unsigned integer underflow deadlock in `ScopeTracker`. Previously, when a declaration closed at parenthesis/brace depth 0, the pop condition `paren_depth < top.depth` evaluated `depth < 0` (impossible for `usize`), causing permanent stack poison and cross-file scope leakage across subsequent files. The updated pop logic cleanly evicts depth-0 frames upon delimiter balance or closer tokens.
   - **Self-Closed Single-Line Declaration Suppression**: Balanced single-line declarations are safely prevented from pushing persistent scope frames.
   - **Multi-Byte UTF-8 & Emoji Identifier Parity**: Retained complete support for Unicode and emoji function/method identifiers while safely enforcing 60-byte boundary truncation without character fragmentation.
