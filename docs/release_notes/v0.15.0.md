# trg v0.15.0 Release Notes

**Release**: `v0.15.0`<br>
**Release Date**: 2026-09-07<br>
**Target Platforms**: `linux-x64`, `macos-arm64`, `windows-x64`, `windows-arm64`<br>
**Toolchain**: Toka SDK 1.0.0-rc.11, Clang/LLVM, MSYS2 MinGW-w64 / CLANGARM64

---

## 1. Overview

`trg v0.15.0` is a milestone release delivering native Windows Tier-1 support across `x86_64` (`windows-x64`) and `aarch64` (`windows-arm64`), alongside full support for Linux and macOS. Windows executables are standalone, dependency-free binaries linked solely against core OS system DLLs, verified via strict PE import table auditing on native runners.

---

## 2. Key Improvements & Fixes

### 1. 原生 Windows 平台支持 (Native Windows x64 & ARM64)
- **Zero Third-Party DLLs**: Binaries link strictly against Windows OS core system libraries (`KERNEL32.dll`, `MSVCRT.dll`, `USER32.dll`, `ADVAPI32.dll`, `WS2_32.dll`). Dependency on third-party runtimes (such as `libwinpthread` or GCC runtimes) is completely eliminated.
- **Strict PE Import Table Auditing**: Automated qualification includes `tests/verify_standalone_binary.py`, which parses the COFF Optional Header and `IMAGE_IMPORT_DESCRIPTOR` table to reject any unapproved DLLs.

### 2. 管道与 I/O 错误处理加固 (Hardened Windows Pipe & Broken Pipe Semantics)
- **Precise EPIPE Normalization**: Windows C bridge (`trg_win_compat.c`) checks whether standard handles refer to pipes and validates the actual Windows error condition (`ERROR_BROKEN_PIPE`, `ERROR_NO_DATA`), preventing generic `EINVAL` or stale `GetLastError()` values from incorrectly returning exit code 0.
- **POSIX Output Layer Isolation**: The common output layer in `src/posix.tk` strictly handles standard `EPIPE` (32) and exits cleanly with code 0 without masking other write failures (exit code 2).

### 3. 严格路径解析与驱动器识别 (Strict Windows Path Resolution)
- Windows path resolution strictly returns errors upon invalid or unreachable drive paths without guessing identities or falling back to arbitrary roots.

### 4. WinGet 官方清单规范 (Windows Package Manager Distribution)
- Generated official WinGet 1.9.0 multi-architecture manifests (`Tokalang.trg`) with `MinimumOSVersion: 10.0.18362.0` targeting portable executables in release ZIP archives.
- Documented upstream catalog publication procedure and review SLA.

### 5. 四平台统一发布门禁 (Authoritative Four-Platform CI Release Gate)
- Release verification runs on native runners: `ubuntu-22.04`, `macos-15`, `windows-2025`, and `windows-11-arm`.
- Release deliverables are strictly managed as a 6-piece deliverable set (`linux-x64.tar.gz`, `macos-arm64.tar.gz`, `windows-x64.zip`, `windows-arm64.zip`, `trg-0.15.0.tar.gz`, `SHA256SUMS`) with non-clobbering, hash-verified draft staging.
