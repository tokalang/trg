## 1. Overview

`trg v0.22.0` is a major feature release dedicated to **Trust & Precision Hydration**. Advancing `trg` from an "agent-friendly" tool to an **absolute trust & precision system**, this release equips autonomous coding agents and human developers with mathematically certain absence verification, skeleton structure folding, and pinpoint in-symbol focus targeting:

1. **Absence Certainty Protocol & Boundary Reliability**:
   - **Tamper-Evident Absence Guarantees**: When a symbol query fails to match, `trg` validates full AST delimiter balance across the target file.
     - Fully balanced and parsed syntax outputs `[status: DEFINITELY_NOT_FOUND, scanned_symbols: N, parse_integrity: 100%]`, providing LLMs with absolute mathematical proof that the symbol does not exist in the file.
     - Files with unclosed braces or recovery degradation output `[status: PARSER_DEGRADED, unclosed_at: L{line}, reason: {reason}]`, preventing agents from falsely assuming an identifier does not exist when a parser anomaly occurred.
   - **Physical Boundary Reliability**: Symbol headers and structured results explicitly indicate physical range certainty:
     - `[boundary: VERIFIED]`: Symbol closing delimiter physically verified and matched.
     - `[boundary: HEURISTIC (indent_inference)]`: Python and indentation-scoped blocks inferred via indentation level.
     - `[boundary: HEURISTIC (eof_fallback)]`: Reached end-of-file fallback.
   - **Precision Progress Badges**: Budget-truncated symbols report exact completion percentage and remaining line counts:
     `[status: TRUNCATED, emitted: L1-L40 (40/120 lines, 33%), remaining: 80 lines]`

2. **Skeleton Fold View (`--fold`)**:
   - **Budget-Preserving Function Outlines**: Inspect large methods (100–1000+ lines) with minimal token consumption. `--fold` preserves the signature line, closing delimiter, and top-level control flow structures (`if`, `else`, `match`, `switch`, `for`, `while`, `try`, `catch`, `return`, `defer`) while collapsing interior loop/branch bodies into compact omission markers (`[... folded: N lines ...]`).
   - **Fold Status Banner**: Displays `[status: FOLDED, shown: M lines, folded: K lines]`.
   - **CLI & MCP Parity**: Accessible via `--fold` in CLI and `"fold": true` in MCP `trg_view`.

3. **In-Symbol Focused Targeting (`--focus <pattern>`)**:
   - **Signature-Anchored Target Windows**: When hunting for a specific variable, call site, or error check inside a massive symbol, `--focus <pattern>` centers a contextual window around the target match while permanently anchoring the symbol's top signature line.
   - **Contextual Line Marking**: The focused target line is clearly highlighted with `:` (`kind: "target"`), while surrounding context lines use `-` (`kind: "context"`).
   - **Front & Rear Continuation Routing**: Gaps before and after the focus window emit actionable continuation markers:
     `[omitted: L2-L6] [continue_via: trg view 'src/view.tk' --lines 2-6]`
   - **Status Banner**: `[symbol: {name}, lines: L{start}-L{end}] [boundary: VERIFIED] [focus: '{pattern}' at L{line}] [status: FOCUSED_VIEW]`.
   - **Absence Diagnostics**: If the pattern is absent within the symbol, returns exit code 1 with stderr:
     `trg view: focus pattern '{pattern}' not found inside symbol '{name}' (L{start}-L{end})`

4. **Qualification & Verification**:
   - Expanded the qualification suite from 186 to **189 rigorous tests**:
     - **Test 187**: Absence Certainty Protocol, Progress Badges & Boundary Reliability (`tests/test_view_absence_certainty.py`)
     - **Test 188**: Skeleton Fold View (`tests/test_view_fold.py`)
     - **Test 189**: In-Symbol Focused Targeting (`tests/test_view_focus.py`)
   - 100% green pass rate across all 189 qualification tests, MCP schemas, and platform installers.

## 2. CLI & MCP Usage Examples

### Absence Certainty Verification
```bash
$ trg view src/view.tk --symbol non_existent_function
trg view: [status: DEFINITELY_NOT_FOUND, scanned_symbols: 84, parse_integrity: 100%]
trg view: symbol 'non_existent_function' not found in src/view.tk
Hint: run 'trg symbols src/view.tk' to view all available symbols in this file
```

```powershell
irm https://raw.githubusercontent.com/tokalang/trg/main/install.ps1 | iex
```

```cmd
winget install --id Tokalang.trg -e
```
