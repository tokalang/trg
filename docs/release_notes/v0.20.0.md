## 1. Overview

`trg v0.20.0` is a major milestone release delivering architectural search performance breakthroughs, first-class Shell scripting support, and comprehensive precision fixes for TypeScript, Vue, and modern Single-File Components:

1. **TS & Vue Multiline Type Declarations & Scope Isolation (TRG-001)**:
   - **Balanced Type Delimiters Tracking**: Introduced `TypeDelimiters` in `src/syntax.tk` to track nested delimiters (`<>`, `()`, `[]`, `{}`) while distinguishing arrow operators (`=>`). Complex multiline type declarations—such as nested generics (`type PreviewPdfPage = Awaited<ReturnType<...>>`), multiline union types, object type literals, and function types—now maintain precise line spans (e.g., L144–L146) instead of collapsing into single-line truncations.
   - **Next-Declaration Boundary Sealing**: Active multiline types are sealed upon encountering subsequent declaration boundaries (`type`, `interface`, `const`, `function`, etc.) or EOF, preventing parallel declarations (e.g. `type PreviewPdfRenderTask = ReturnType<...>`) from being swallowed or corrupted.
   - **Enclosing Scope Purity**: TypeScript `type` aliases are strictly excluded from `is_scope_declaration_with_dialect`. Types never act as parent enclosing scopes, eliminating spurious child scope nesting.

2. **Vue, Svelte, and Astro SFC Symbol View Support (TRG-002)**:
   - **Hydration Parity**: Added `.vue`, `.svelte`, and `.astro` Single-File Components to `is_symbol_view_supported` in `src/syntax.tk`.
   - Modern web component symbols can now be hydrated and inspected directly with `trg view <file> --symbol <name>` with exact file line numbers.

3. **600x Search Performance Acceleration (TRG-003)**:
   - **Alternation Literal Prefiltering**: Implemented `extract_alternation_literals` in `src/matcher.tk`. Patterns consisting of alternation literals (e.g., `pdfium|webview` or `(foo|bar|baz)`) extract branch literals during regex compilation. A fast-path substring check evaluates candidate lines before executing the Thompson NFA engine, short-circuiting non-matching lines instantly.
   - **Lexical Scan Bypass Gateway**: Plain CLI text searches (where `--scope`, `--block`, `--def-first`, or `--code-only` are not requested) now conditionally bypass `compute_line_indent`, `scan_line_lexical_with_mask`, and `ScopeTracker::update` in `src/scanner.tk`.
   - **Empirical Benchmark**: On representative multi-directory, multi-glob alternation queries, latency drops from **3592.9 ms to 5.86 ms** (~600x speedup), matching and rivaling `ripgrep` throughput while preserving full semantic capabilities on demand.

4. **First-Class Shell Script Support & Heredoc Isolation Defense (TRG-004)**:
   - **Bash Lexical Dialect**: Added `LexicalDialect::Bash` supporting `.sh`, `.bash`, and `.zsh` files.
   - **Dual Function Syntax Support**: Accurately recognizes both POSIX-standard `name() { ... }` and Bash-style `function name { ... }` definitions.
   - **Heredoc Lexical Isolation**: Implemented `extract_heredoc_tag` and state tracking for `<<TAG`, `<<'TAG'`, `<<"TAG"`, and `<<-TAG`. Embedded multiline scripts (e.g., Node.js or Python snippets executed within shell scripts) are completely masked as strings, preventing embedded braces from corrupting outer shell function depth and eliminating foreign arrow functions from leaking as symbols.

5. **Qualification & Verification**:
   - Expanded the rigorous qualification suite to **183 tests**, introducing Test 183 (`tests/test_bash_symbols.py`) and expanding Test 182 (`tests/test_ts_vue_symbols.py`).
   - 100% green pass rate across all 183 qualification tests and universal regression matrices.

## 3. Quick Installation

### macOS & Linux
```bash
curl -fsSL https://raw.githubusercontent.com/tokalang/trg/main/install.sh | sh
```

### Windows (PowerShell)
```powershell
irm https://raw.githubusercontent.com/tokalang/trg/main/install.ps1 | iex
```

### Windows (WinGet)
```cmd
winget install --id Tokalang.trg -e
```
