## 1. Overview

`trg v0.21.0` is a major feature release dedicated to **Agent-Native Developer Experience (DX) & Zero-Friction Hydration**. Built specifically for autonomous AI coding agents and human developers alike, this release transforms diagnostic roadblocks and truncation events into seamless, single-hop actionable routes:

1. **Anti-Hallucination Status Banners & Truncation Perception (TRG-005)**:
   - **In-Body Status Banners**: Plain-text output and MCP `content[0].text` now embed standardized, tamper-evident status banners at the top of hydration results:
     - `[status: COMPLETE, lines: 1-12 of 12, range: L1-L12]`
     - `[status: UNCLOSED, lines: 1-5 of 12, range: L1-L5, reason: max_lines, remaining: 7 lines]`
     These banners give LLMs unambiguous visibility into whether code is fully enclosed or truncated due to token/line limits, eliminating premature assumptions and hallmarked syntax guessing.
   - **Self-Healing Continuation Commands**:
     - CLI truncation notices now embed ready-to-execute next-step commands: `[omitted 7 lines. Continue: trg view 'src/view.tk' --lines 6-12]`.
     - Symbol-mode truncations provide continuation tokens: `trg view 'src/view.tk' --symbol 'foo' --continuation-token '...'`.
   - **Structured `next_request` for MCP**:
     - In MCP `trg_view` responses, truncated outputs now include a structured `next_request` object inside `structuredContent`:
       ```json
       "next_request": {
         "tool": "trg_view",
         "arguments": {
           "path": "/path/to/file.tk",
           "symbol": "foo",
           "continuation_token": "..."
         }
       }
       ```
     - LLM tool-calling loops can invoke the next page immediately with zero prompt overhead or manual line arithmetic.

2. **Actionable Symbol Disambiguation & Single-Hop Routing (TRG-006)**:
   - **CLI `query_cli` Routing Directives**: When querying a duplicate symbol name, `trg` presents candidate definitions alongside instant copy-paste commands:
     ```text
     Multiple candidates found for symbol 'start':
       line 1: function start - def start():
         -> query_cli: trg view 'server.py':1 --block
       line 5: method start (scope: Server) - def start(self):
         -> query_cli: trg view 'server.py' --symbol 'Server::start'
     ```
   - **Strict Compatibility & Budget Resilience**: Preserves standard `line N: {kind} {name}` prefix contracts and gracefully degrades `query_cli` hints if budget limits (e.g., `--max-bytes 230`) are saturated.
   - **MCP Structured Candidate Queries**: Each candidate in the MCP `candidates` array provides a pre-formed `query` property (`{"tool": "trg_view", "arguments": ...}`) enabling single-hop agent dispatch.

3. **Intelligent Typo Recovery & Scope Routing (TRG-007)**:
   - **"Did you mean?" Typo Suggestions**: When a symbol query fails to match, `trg` evaluates Levenshtein edit distances against symbols in the target file, detecting misspellings and offering exact replacement commands (e.g. `dispath` -> `dispatch`).
   - **Autonomous Scope Routing**: If an unscoped query matches a method defined within a class or namespace (e.g. querying `start` when `Server::start` exists), `trg` guides the caller to the scoped identifier:
     `Symbol 'start' not found, but found in scope 'Server'. Did you mean '--symbol Server::start'?`
   - **Actionable Outline Hints**: Inconclusive queries offer clear next steps (`Hint: run 'trg symbols <path>' or call MCP 'trg_symbols' to inspect all symbols in this file.`).
   - **MCP `suggestions` Schema**: Structured suggestions are returned via `structuredContent.suggestions` with ready-to-call `query` objects.

4. **Qualification & Verification**:
   - Expanded the qualification suite from 183 to **186 rigorous tests** (Test 184: Banner & Continuation, Test 185: Disambiguation Routing, Test 186: Typo Suggestions & Scope Recovery).
   - 100% green pass rate across all 186 tests, MCP schemas, and platform installers.

## 3. Quick Installation

### macOS & Linux
```bash
curl -fsSL https://raw.githubusercontent.com/tokalang/trg/main/install.sh | sh
```

### Windows (PowerShell)
```powershell
irm https://raw.githubusercontent.com/tokalang/trg/main/install.ps1 | iex
```

### Windows (WinGet)
```cmd
winget install --id Tokalang.trg -e
```
