# trg v0.19.3 Release Notes

**Release**: `v0.19.3`<br>
**Release Date**: 2026-09-11<br>
**Target Platforms**: `linux-x64`, `macos-arm64`, `windows-x64`, `windows-arm64`<br>
**Toolchain**: Toka SDK 1.0.0-rc.11, Clang/LLVM, MSYS2 MinGW-w64 / CLANGARM64

---

## 1. Overview

`trg v0.19.3` 是一个聚焦于**显式预算下的大符号截断预览**、**结果驱动的轻量级操作提示层**与**跨平台执行正确性**的重要版本：

1. **显式预算符号预览与未读切片投影 (Bounded CLI Symbol Preview Under Explicit Budgets)**:
   - 在用户显式指定 `--max-lines` 或 `--max-bytes` 预算时，对大符号输出确定性前向裁剪预览（`CliSymbolPreviewProjection`）；
   - 输出清晰的行范围与省略说明标牌（例如 `[func_name lines 1-5 of 120 shown; remaining 115 lines omitted]`）；
   - 预览裁剪同步收缩文本、行数、字节数以及精确的未读范围（`shown_range`、`omitted_ranges`、`lines_emitted`、`bytes_emitted`），确保后续操作提示准确反映实际未读位置；
   - 严格限定仅在用户显式设置预算且发生实际截断的非 continuation 模式下触发预览裁剪，避免未知边界保护性限制产生误导。

2. **结果驱动的轻量级操作提示层 (Result-Driven Lightweight Action Hints & `--no-hints`)**:
   - 在 CLI 人类交互模式下提供单点槽位提示（Single-Slot Hint），至多在 stderr 输出一条确定性、高置信度的后续行动建议（≤ 1024 字节）；
   - 提供 `--no-hints` 全局标志，方便用户及脚本按需关闭提示；
   - 覆盖五大核心场景，并全面加固安全与预算继承：
     - **参数与选项诊断**：未知选项或参数语法错误时提供正确用法建议；
     - **正则语法诊断**：保持退出码 `2` 与稳定的 `INVALID_REGEX` 错误码；在 `-q`（静默）与 `--no-hints` 下均安全抑制提示，杜绝错误分支冗余输出；
     - **符号作用域消歧**：跨文件多重定义时提示带精确作用域的读取命令；
     - **预算截断与续读提示**：大符号预览后推荐实际未读切片的读取命令（`--lines <start>-<end>`），并严格继承原有的 `--max-lines` 和 `--max-bytes` 预算，杜绝无预算重读与全量展开；同时保证协议续读 token 提示不受 1 KiB 建议上限截断；
     - **单命中精确定位**：单文件单次命中时提示带作用域和行号的定位命令；严格排除多模式搜索（`-e p1 -e p2`）、管道与 stdin（`-`）、提取模式（`-o`）、计数（`-c`）、清单（`-l`）及已有上下文等不可重构场景。

3. **跨平台严格 Shell 转义与真实 Shell 验证 (Cross-Platform Shell Escaping & Safe Execution)**:
   - 提示命令针对目标平台生成符合 Shell 语法规范的参数引用（POSIX `/bin/sh` 与 Windows PowerShell）；
   - 覆盖包含空格、单引号、中文字符以及前导短横杠 `-` 等复杂路径情况，并在四平台 CI 原生 Shell 环境中全量通过真实命令执行验证；
   - 严格基于真实输入身份（文件 vs stdin）判断候选资格，记录规范化绝对物理路径，确保建议命令可直接复制并在任意工作目录安全执行。
