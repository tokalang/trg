**Release**: `v0.16.0`<br>
**Release Date**: 2026-09-07<br>
**Target Platforms**: `linux-x64`, `macos-arm64`, `windows-x64`, `windows-arm64`<br>

---

## 1. Overview

`trg v0.16.0` is a milestone release introducing **Instant Symbol Outline & Semantic Alignment**. Building on top of `trg`'s ultra-fast streaming search and hydration core, `v0.16.0` delivers instant symbol extraction (`trg symbols` CLI subcommand and native `trg_symbols` MCP tool) with pure $O(1)$ streaming memory and sub-millisecond execution, paired with three core syntactic semantic alignments across Go receiver methods, TypeScript/JavaScript arrow functions, and multiline decorators/attributes.

---

## 2. Key Improvements & Fixes

### 1. 即时符号大纲与范围萃取 (Instant Symbol Outline & Range Extraction)
- **CLI 子命令 (`trg symbols <PATH> [OPTIONS]`)**:
  - 提供文本大纲（缩进层次视图）与机器友好 JSONL 流式输出（`--json`）。
  - 支持按类型过滤（`-k / --kind function,method,class,...`）、符号数量上限（`--max-symbols <N>`）与字节预算上限（`--max-bytes <B>`）。
  - 输出 Edit-Ready 的完整语义范围 `[start, end]`（首行至末行闭合行号），供 AI Agent 直接发起局部精准重构与补丁替换。
- **原生 MCP 工具 (`trg_symbols`)**:
  - 全面支持 MCP 协议版本双通道协商（`2024-11-05` 与 `2025-11-25`）。
  - 具备结构化输入契约（`path`、`kinds`、`max_symbols`、`max_bytes`）与规范输出（`symbols`、`total_symbols`、`limits`）。
  - 内置工作区根目录越界拦截保护（Root Traversal Guard），防止遍历系统敏感路径。
- **纯流式轻量架构 (Pure $O(1)$ Memory & Zero Heavy AST)**:
  - 延续 `trg` 的零树解析（Tree-free）哲学，不依赖庞大且缓慢的 Tree-sitter 或 AST 解释器，流式单遍处理超大源文件，内存恒定保持在微秒级释放。

### 2. 三项语法语义对齐 (Ride-Along Syntactic Semantic Alignments)
- **Go 语言接收者方法与泛型支持 (Go Receiver Methods & Generics)**:
  - 精准识别 `func (s *Server) Start()` 与泛型方法 `func (s *Stack[T]) Push()`，正确提取方法名称，绑定容器上下文，并将符号类型标记为 `method`。
  - 严格排除匿名闭包（如 `go func() { ... }()`），避免符号表假阳性污染。
- **TypeScript / JavaScript 箭头函数精准定界 (TS/JS Arrow Functions)**:
  - 智能区分块体箭头函数（`const fn = () => { ... }`，提取闭合范围）与单行自闭合表达式（`export const square = x => x * x;`，自动收敛为 `[start, start]`）。
  - 具备引号敏感的状态机（Quote-Aware State Machine），彻底消除在数组、对象、模板字面量中包含 `=>` 字符串字面量（如 `const arr = ["foo => bar"]`）引起的假阳性误判。
- **多行装饰器与注解向上吸附 (Multiline Decorator & Attribute Upward Snapping)**:
  - 在函数、类、方法定义上方自动吸附关联的 `@decorator`（Python / TypeScript / Java / C#）与 `#[attribute]`（Rust）。
  - 完整跟踪多行圆括号与方括号的平衡闭合（`@route(\n  "/api",\n  methods=["POST"]\n)`），并在遇到空行时硬停止，确保上下文吸附严谨可信。
